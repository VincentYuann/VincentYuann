# Product

## Platform

web

## Users
Technical recruiters, engineering hiring managers, CTOs, and peer developers evaluating Vincent Yuann for Full-Stack, Distributed Systems, and Applied AI engineering roles.

## Product Purpose
An interactive, high-craft engineering portfolio and systems showcase designed to prove architectural depth, software engineering discipline, and production-grade execution through verifiable projects, deep-dive engineering logs, and interactive tooling.

## Positioning
Unlike generic portfolio templates or static landing pages, this portfolio is itself an engineered distributed web system: featuring zero-flash multi-theming, client-side AST LaTeX tokenization, zero-leak serverless contact pipelines, and an administrative CMS studio backed by Supabase PostgreSQL and Row-Level Security.

## Operating Context
Browsed on desktop, tablet, and mobile by evaluators who spend 30-90 seconds assessing technical substance. Key workflows: scanning flagship systems, inspecting architectural highlights and source repositories, viewing synchronized PDF and LaTeX resumes, switching themes, or navigating rapidly via keyboard command palette (`⌘K`).

## Capabilities and Constraints
- Single Page Application with client-side hash routing for GitHub Pages compatibility.
- Multi-theme engine (7 OKLCH palettes) with instant, zero-flash persistence.
- Administrative CMS protected by GitHub OAuth and PostgreSQL Row-Level Security.
- Rate-limited serverless contact gateway with Honeypot bot protection.
- Global command palette spotlight search (`⌘K`).

## Product Principles
1. Depth over fluff: Prioritize concrete architectural invariants, patterns, and code links over superficial marketing claims.
2. The artifact is the proof: The portfolio's performance, accessibility, security, and responsive craft must embody the engineering standards it claims.
3. Frictionless evaluation: Provide immediate keyboard navigation, clear visual hierarchy, and fast reading paths.
4. Respectful and resilient: Zero white flash on dark theme reload, no intrusive trackers, and strict privacy protection.
